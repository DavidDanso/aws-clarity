## 3. Platform Installation Instructions (Once `v1.1.0` Is Published)

### A. macOS (Python 3.10+)

1. **Download the `v1.1.0` wheel and `SHA256SUMS.txt`** (once `v1.1.0` is published):
   ```bash
   mkdir -p ~/Downloads/aws-clarity-v1.1.0 && cd ~/Downloads/aws-clarity-v1.1.0
   curl -fLO https://github.com/DavidDanso/aws-clarity/releases/download/v1.1.0/aws_clarity-1.1.0-py3-none-any.whl
   curl -fLO https://github.com/DavidDanso/aws-clarity/releases/download/v1.1.0/SHA256SUMS.txt
   ```
2. **Verify the SHA-256 checksum** (and optional GitHub SLSA provenance attestation):
   ```bash
   shasum -a 256 -c --ignore-missing SHA256SUMS.txt
   # Expected: aws_clarity-1.1.0-py3-none-any.whl: OK

   # Optional cryptographic provenance verification (requires GitHub CLI `gh`):
   gh attestation verify aws_clarity-1.1.0-py3-none-any.whl --repo DavidDanso/aws-clarity
   ```
   > A SHA-256 checksum verifies download integrity against `SHA256SUMS.txt`; it is not a digital signature. Use `gh attestation verify` for GitHub Actions build provenance.
3. **Install into an isolated environment (`pipx` or `venv`)**:
   ```bash
   # Option 1 — pipx (recommended):
   pipx install ./aws_clarity-1.1.0-py3-none-any.whl

   # Option 2 — standard Python venv:
   python3 -m venv ~/.aws-clarity
   ~/.aws-clarity/bin/pip install ./aws_clarity-1.1.0-py3-none-any.whl
   ```
4. **Verify CLI version and help**:
   ```bash
   aws-clarity version
   # Expected: aws-clarity 1.1.0 (local-first, read-only, zero telemetry)
   aws-clarity --help
   aws-clarity scan --help
   ```
   *(If using `venv`, prefix with `~/.aws-clarity/bin/aws-clarity`.)*

## 4. Selecting a Dedicated Read-Only AWS Profile or Role

Before running a scan against any AWS account:

1. **Create or select a dedicated least-privilege read-only identity** (do not use AWS root credentials — refused by default — or `AdministratorAccess`):
   - Print the exact 28-action default policy locally: `aws-clarity policy --zero-cost-only` (or `aws-clarity policy` for 34 actions including optional S3).
   - Or deploy the provided customer-owned CloudFormation template [`infra/aws-clarity-readonly-role.yaml`](../infra/aws-clarity-readonly-role.yaml) in your own account.
2. **Authenticate and verify your target AWS account**:
   ```bash
   aws sso login --profile my-readonly-profile
   aws sts get-caller-identity --profile my-readonly-profile
   ```
3. **Probe permissions and enabled regions locally before scanning**:
   ```bash
   aws-clarity doctor --profile my-readonly-profile
   ```
4. **Run a local read-only scan** (default 9 zero-request-charge services; S3 skipped unless `--include-s3-checks` is explicitly supplied):
   ```bash
   aws-clarity scan --profile my-readonly-profile --output aws-clarity-report.json
   ```
   Or assume a dedicated read-only role locally without any cross-account trust to AWS Clarity:
   ```bash
   aws-clarity scan --profile my-profile --role-arn arn:aws:iam::123456789012:role/AWSClarityReadOnlyRole --output aws-clarity-report.json
   ```
